# تطبيق لوحة حمص للتلفاز

## الطريقة الأسهل: بناء الـ APK على GitHub (بدون تثبيت أي برنامج)
1. أنشئ حساباً مجانياً على github.com ثم اضغط **New repository** (اسمه مثلاً HomsTV).
2. اضغط **uploading an existing file** وارفع **كل محتويات** هذا المجلد بعد فك الضغط
   (بما فيها المجلد المخفي `.github`، إن لم يظهر عندك فعّل إظهار الملفات المخفية).
3. اذهب لتبويب **Actions** ثم **Build APK** ثم **Run workflow**.
4. بعد دقيقتين إلى ثلاث افتح التشغيلة المكتملة ونزّل **HomsTV-apk** من قسم Artifacts (ملف ZIP بداخله app-debug.apk).

## الطريقة الثانية: Android Studio
افتح المجلد في Android Studio، انتظر المزامنة، ثم **Build > Build APK(s)**.

## التثبيت على التلفاز
- انسخ الملف على فلاشة USB وافتحه من مدير الملفات في التلفاز، أو أرسله بتطبيق **Send Files to TV**، أو استخدم `adb install app-debug.apk`.
- فعّل **مصادر غير معروفة** عند الطلب.
- سيظهر التطبيق باسم **لوحة حمص** في قائمة التطبيقات.

## ملاحظات
- الطقس مباشر (Open-Meteo) ويحتاج إنترنت، وبدونه يعرض متوسطات الشهر.
- التشغيل التلقائي عند إقلاع التلفاز موجود لكن أندرويد 14 قد يمنعه في بعض الأجهزة. الحل: افتح التطبيق يدوياً أو ضعه في المفضلة.
- لتعديل الواجهة عدّل الملف `app/src/main/assets/index.html` ثم أعد البناء.
