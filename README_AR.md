# لوحة حمص عاصمة الثورة (تطبيق تلفاز) - النسخة 3.2

## البناء
ارفع كل محتويات المجلد على GitHub، ثم Actions > Build APK > نزّل app-debug.apk.
احذف النسخة القديمة قبل تثبيت الجديدة.

## أزرار الريموت
- OK: شاشة تعديل دقائق الأذان.
  - ▲▼ للتنقل، ◄ ► لنقصان أو زيادة الدقائق (مع إبقاء الضغط للتكرار).
  - الصف «تكبير الأذان» لتشغيل أو إيقاف التكبير، «إعادة ضبط»، ثم «حفظ وإغلاق». Back للإغلاق.
- ◄ (خارج الإعدادات): إطفاء الشاشة (شاشة سوداء). أي زر يرجّعها.
- ▲: تشغيل/إيقاف تكبير الأذان. ▼: تجربة الصوت.
- Back: لا يغلق التطبيق، بل يتركه يعمل بالخلفية.

## تشغيل الأذان بالخلفية
- يبدأ التطبيق خدمة أمامية خفيفة (إشعار صغير) تبقيه حيّاً، ومعها منبّه نظام، ومعها فحص احتياطي كل 15 ثانية.
- تعمل الخدمة تلقائياً بعد إعادة تشغيل التلفاز.
- أوامر مرة واحدة عبر ADB لمنع النظام من إيقاف التطبيق:
  adb shell cmd deviceidle whitelist +sy.homs.dash
  adb shell appops set sy.homs.dash RUN_IN_BACKGROUND allow
  adb shell appops set sy.homs.dash RUN_ANY_IN_BACKGROUND allow
  adb shell appops set sy.homs.dash SYSTEM_ALERT_WINDOW allow
- لصوت حقيقي ضع takbeer.mp3 في app/src/main/assets قبل البناء.
